## Napište vědecký název veškerého ptactva, které splňuje současně následující kritéria: vyskytuje se v Evropě, je téméř ohrožené a jsou hmyzožravci.
V datasetu a databázi splňují tato kritéria tyto druhy:
- Coracias garrulus
- Vanellus vanellus
- Numenius arquata

## Napište SQL dotaz, kterým lze získat informaci z předchozí otázky. Budete muset najít způsob, jak takový dotaz získat. Do odpovědi nevkládejte dotaz, který obsahuje proměnné.
```sql
SELECT vedecky_nazev
FROM ptaci
WHERE vyskyt_kontinent = 'Evropa'
  AND status_ohrozeni = 'Téměř ohrožený'
  AND typ_potravy = 'hmyzožravec';
```

## Jak se do HTML šablony dostanou data o ptactvu, která si uživatel nechal vypsat s použitím filtru? Do odpovědi vložte volání funkce, kde se tak děje.
Filtrovaná data se nejdřív načtou do proměnné `ptaci` a potom se předají do šablony přes `render_template()`.

```python
return render_template(
    "dashboard.html",
    ptaci=ptaci,
    filter_options=filter_options,
    params=request.args,
    stats=stats,
    graf_rad_labels=graf_rad_labels,
    graf_rad_data=graf_rad_data,
    graf_potrava_labels=graf_potrava_labels,
    graf_potrava_data=graf_potrava_data,

    graf_migrace_data=graf_migrace_data,
    graf_kontinent_labels=graf_kontinent_labels,

```
