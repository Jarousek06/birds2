# Úkol 1

## Jaký programovací jazyk a v jaké verzi vaše aplikace využívá?
Aplikace je napsaná v jazyce Python ve verzi 3.13.7.

## Jaký framework (pokud vůbec) a v jaké verzi je použit pro tvorbu webové aplikace?
Pro webovou aplikaci je použit framework Flask ve verzi 3.1.3.

## Jakého správce balíčků používáte v rámci vaší aplikace?
Používáme správce balíčků pip v rámci virtuálního prostředí `.venv`.

## Jaký typ databáze aplikace vužívá?
Aplikace využívá relační databázi SQLite.

## Jak vypadá connection string do databáze?
Connection string je `sqlite3.connect("ptaci.db")`.
